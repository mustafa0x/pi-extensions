# recap-luna

Adds `/recap-luna [instructions]`, `/recap-luna-show`, and `/recap-luna-copy`. Recaps default to `openai-codex/gpt-5.6-luna` at `xhigh`, list the concrete work completed during the session, persist in the session, and do not compact or change the active session model.

Install through the root repository package. See [the root README](../../README.md) for configuration.
